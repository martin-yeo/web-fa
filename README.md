# 교수 참고 보드 (web-fa)

## 무엇인가요

기말 프로젝트 스타터 v3에 실습과제 #3의 보드를 옮겨 놓은 교수 참고 구현입니다.<br>
#3 정답 예시의 `renderCards`, `getView`, 찜 코드를 STARTER.md 7절 "바꿔야 하는 4 곳"대로 재사용했고, 카드를 누르면 `detail.html?id=영화번호`의 상세로 갑니다.<br>
바꾼 파일은 `index.html`, `board.js`, `board.css`, `detail.js`, `detail.css` 5개뿐이고, 나머지는 스타터 v3과 같습니다(`keys.js`는 값이 빈 채로 들어 있음).

## 누구를 위한 것인가요

- 실습과제 #3을 끝내지 못해 기말 프로젝트 보드로 옮길 코드가 없는 학생
- #3을 끝낸 학생도 내 옮기기와 비교해 보는 용도로 누구나 볼 수 있습니다.

## 언제

13주차 수업에 공개합니다(12분반 11/25(수), 11분반 11/30(월)).

## 가져가는 법

1. 이 저장소에서 `index.html`, `board.js`, `board.css`, `detail.js`, `detail.css` 5개를 엽니다(파일 클릭 ⇒ "Raw" 옆 복사 아이콘).
2. 내 `web-final`의 같은 이름 파일에 덮어씁니다.<br>
   내가 이미 고친 곳이 있으면 덮어쓰기 전에 두 파일을 비교해서 옮깁니다.
3. `config.js`, `keys.js`, 그 밖의 파일은 내 것을 그대로 둡니다(이 저장소의 `config.js`는 가져오지 않음).
4. 커밋, 동기화 ⇒ 배포 사이트에서 보드와 상세를 확인합니다.

## 이미 있는 것과 여전히 내 몫

| 이미 있는 것 | 여전히 내 몫 |
|---|---|
| 필수 1: TMDB 상영 중 목록을 #3 카드로(평점 배지, 8점 이상 강조, 대체 표지, 평점 0은 "평점 없음", 개봉일 없으면 "개봉일 미정") | 필수 2: 검색창에서 Enter ⇒ `search/movie`로 다시 불러오기(지금 검색창은 받은 목록 안에서만 거름) |
| 필수 3: 정렬 3가지(평점순, 최신 개봉순, 제목 가나다순), 검색 결과에도 적용 | 필수 4: 상세에 목록에 없던 정보 2개 이상(장르, 상영시간 등) |
| 필수 4의 일부: 카드 ⇒ `detail.html?id=` ⇒ `movie/{id}`로 포스터 w500, 제목, 개봉일, 평점, 줄거리 | 필수 5: 찜 모두 지우기 버튼 |
| 필수 5의 일부: ♥ 찜 토글, 찜 개수, 새로고침 뒤 유지(`final-liked`에 영화 id) | 필수 6: KOBIS 박스오피스 + TMDB 영화 포스터 매칭 |
| 상태 3종: 로딩, 빈 결과("조건에 맞는 영화가 없습니다."), 오류(이유 포함) | #1 디자인으로 꾸미기(지금은 수수한 기본 모양), 플러스원 페이지 |

## 조건

- `board.js`, `detail.js` 머리 주석의 **출처 줄**(`출처: 교수 참고 보드 web-fa(...)`)은 지우지 않습니다.
- 내 `web-final` README 맨 위 목록에 한 줄을 적습니다: `- 보드 출발점: 교수 참고 보드(web-fa)`
- 이 코드도 14주차 순회 코드 질문의 대상입니다(내 사이트 코드로 보고 묻습니다). 줄마다 무슨 일을 하는지 설명할 수 있게 읽어 둡니다.
- 가져와 써도 감점은 없습니다. 실습과제 #3 점수는 `web-hw3`로 따로 매깁니다.

## 할 일 목록(Todo Tree, 선택)

이 저장소에는 이미 만든 기능(필수 1, 3, 찜)의 `TODO`는 없고, 남은 내 몫만 `TODO 필수 n` 주석으로 남아 있습니다(필수 2의 Enter 검색, 필수 4의 정보 2개, 필수 5의 찜 모두 지우기 버튼, 필수 6 등).<br>
가져가는 5개 파일에도 그 줄이 함께 옵니다. VS Code 확장 Todo Tree나 `Ctrl+Shift+F`의 `TODO` 검색으로 모아 보고, 끝낸 줄은 지웁니다(설치는 PC실 안내서 7-4절).

## 이 저장소의 사이트

`https://martin-yeo.github.io/web-fa/`는 `keys.js`의 키가 비어 있어 샘플 모드(가상 영화 12편, 포스터 없음 ⇒ 대체 표지)로 보입니다.<br>
화면 위 띠 "샘플 모드(TMDB, KOBIS): keys.js에 TMDB, KOBIS 키가 없어 …"는 정상입니다(일부러 키 없이 올렸습니다. 내 사이트에서는 내 `keys.js`의 키로 돕니다).
